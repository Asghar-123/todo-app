# Research: AI-powered Todo Chatbot

## Frontend Testing Framework

**Decision**: Jest / React Testing Library

**Rationale**: OpenAI ChatKit is React-based. Jest is a widely adopted JavaScript testing framework, and React Testing Library provides utilities for testing React components in a user-centric way, making them a standard and effective combination for React applications.

**Alternatives considered**: Cypress (end-to-end focus, more heavyweight for unit/component testing), Enzyme (older, less preferred for React 16+).
